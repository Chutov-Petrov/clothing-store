# Ткань — интернет-магазин одежды

Учебный проект: полноценный интернет-магазин одежды с клиентской и административной частью.
Реализован на **Python/Flask**, работает на **SQLite**, без внешних фреймворков на фронтенде.

## ✨ Возможности

### Для покупателя
- **Каталог** с фильтрами по категориям, поиском и сортировкой (по цене, новизне)
- **Пагинация** — по 12 товаров на страницу с умным диапазоном страниц
- **Карточка товара** — галерея фото, характеристики (материал, уход), остатки на складе
- **Корзина** — добавление, изменение количества, удаление, очистка
- **Промокоды** — процентные и фиксированные скидки, лимиты по сумме и использованию
- **Избранное** — добавление без перезагрузки страницы (AJAX)
- **Регистрация и вход** с проверкой сложности пароля
- **Личный кабинет** — редактирование профиля, смена пароля, история заказов
- **Детали заказа** — полный состав, статус, кнопка «Повторить заказ»
- **Отзывы** с рейтингом (5 звёзд, только авторизованные, один отзыв на товар)
- **Адаптивный интерфейс** — работает на мобильных
- **Тёмная/светлая тема** — автоматически по системным настройкам

### Для администратора
- **Управление товарами** — создание, редактирование, удаление
- **Загрузка фото** — до 6 изображений на товар, проверка формата и содержимого
- **Заказы** — просмотр состава, смена статуса (Новый → Оплачен → Отправлен → Доставлен)
- **Отзывы** — модерация и удаление
- **Промокоды** — создание, включение/отключение, удаление, статистика использования
- **Журнал входов** — IP, логин, роль, результат (успех/отказ), User-Agent, время

## 🔒 Безопасность (OWASP Top 10:2025)

Проект прошёл аудит по всем 10 категориям OWASP 2025.

| Категория | Реализация |
|---|---|
| **A01** Контроль доступа | Декоратор `@admin_required`, CSRF на всех POST |
| **A02** Настройки по умолчанию | `debug=False`, секреты в `config.py`, нет дефолтных паролей |
| **A03** Цепочка поставок | Фиксация версий в `requirements.txt` (`==`) |
| **A04** Криптография | PBKDF2-HMAC-SHA256, 200 000 итераций, соль 16 байт, `hmac.compare_digest` |
| **A05** Инъекции | Параметризованные SQL-запросы, Jinja2 автоэскейп, проверка magic bytes |
| **A06** Небезопасный дизайн | Транзакция `BEGIN IMMEDIATE` при checkout, списание в одном блоке |
| **A07** Аутентификация | Rate limit (5 попыток / 15 минут), блокировка, сложность пароля |
| **A08** Целостность данных | `PRAGMA foreign_keys = ON` для всех соединений |
| **A09** Логирование | Таблица `login_log`, вкладка «Журнал входов» в админке |
| **A10** Обработка НС | `try/except` с `ROLLBACK`, кастомные страницы 403/404/429 |

**Дополнительные меры:**
- CSRF-токен обязателен для всех POST-запросов (глобально через `before_request`)
- Пароли хранятся как `pbkdf2_sha256$<iters>$<salt>$<hash>`
- Имена загружаемых файлов генерируются случайно (`secrets.token_hex(16)`)
- Проверка magic bytes: PNG, JPEG, WEBP
- Защита от IDOR — заказы доступны только владельцу
- `SECRET_KEY` и `ADMIN_PASSWORD` — в отдельном файле `config.py`

## 🚀 Установка и запуск

### Требования
- **Python 3.12** или выше
- **pip** (менеджер пакетов)

### Шаги

```bash
# 1. Перейти в папку проекта
cd ткан

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
python app.py
```

### Открыть в браузере
```
http://127.0.0.1:5000
```

При **первом запуске** автоматически:
- Создаётся база данных `shop.db`
- Добавляются **33 товара** (8 футболок, 8 верхней одежды, 8 брюк, 9 платьев)
- Создаются **3 демо-промокода**: `WELCOME10`, `SALE500`, `VIP20`

## 👤 Доступы

### Администратор
- **URL входа:** http://127.0.0.1:5000/login
- **Логин:** `admin` (или `админ`)
- **Пароль:** задаётся в `config.py` (по умолчанию `Qwerty!2026Admin`)
- **После входа:** редирект в `/admin`

### Покупатель
- **Регистрация:** http://127.0.0.1:5000/register
- **Требования к паролю:** минимум 8 символов, заглавная, строчная, цифра
- **Вход:** http://127.0.0.1:5000/login

## 🏗 Архитектура

### Application Factory

Точка входа — `app.py`, функция `create_app()`. Это позволяет:
- Легко тестировать приложение (создавать разные конфигурации)
- Не захламлять глобальное состояние
- Использовать несколько экземпляров (например, в тестах)

### Blueprints

Приложение разбито на 6 логических модулей:

| Blueprint | URL-префикс | Ответственность |
|---|---|---|
| `auth_bp` | `/`, `/register`, `/login`, `/profile` | Регистрация, вход, профиль, детали заказа |
| `catalog_bp` | `/`, `/catalog`, `/product` | Главная, каталог, товар, отзывы |
| `cart_bp` | `/cart` | Корзина, промокоды, checkout |
| `wishlist_bp` | `/wishlist` | Избранное |
| `admin_bp` | `/admin` | Админка |
| `pages_bp` | `/about`, `/delivery`, `/payment`, `/contacts` | Статические страницы |

### Слои

1. **Presentation** — Jinja2-шаблоны + CSS
2. **Views (Routes)** — Flask Blueprints
3. **Business Logic** — helpers.py (`calc_discount`, `cart_totals`, `enrich`)
4. **Data Access** — `db.py` (`db()`, запросы через SQLite)
5. **Domain** — таблицы `products`, `orders`, `users`, `reviews`, `promocodes` и др.
