## 🔒 Безопасность

Проект прошёл аудит по **OWASP Top 10:2025**.

| Категория | Реализация |
|---|---|
| **A01** Контроль доступа | `@admin_required`, CSRF на всех POST, защита от IDOR |
| **A02** Настройки по умолчанию | `debug=False`, секреты в `config.py` |
| **A03** Цепочка поставок | Фиксация версий (`==`) в `requirements.txt` |
| **A04** Криптография | PBKDF2-HMAC-SHA256, 200 000 итераций, соль 16 байт |
| **A05** Инъекции | Параметризованный SQL, Jinja2 escape, magic bytes |
| **A06** Небезопасный дизайн | `BEGIN IMMEDIATE` транзакция при checkout |
| **A07** Аутентификация | Rate limit (5 попыток / 15 мин), блокировка |
| **A08** Целостность данных | `PRAGMA foreign_keys = ON` |
| **A09** Логирование | Таблица `login_log`, журнал входов в админке |
| **A10** Обработка НС | `try/except` + `ROLLBACK`, кастомные страницы 403/404/429 |

**Дополнительные меры:**
- 🔑 Пароли: `pbkdf2_sha256$<iters>$<salt>$<hash>`
- 🖼 Загружаемые файлы: случайное имя + проверка magic bytes (PNG/JPEG/WEBP)
- 🛡 CSRF-токен обязателен для всех POST-запросов
- 🔐 `hmac.compare_digest` — защита от timing-атак
- 👤 Заказы доступны только владельцу (защита от IDOR)

## 🚀 Установка

### Требования

- **Python 3.12+**
- **pip**

### Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ваш-логин/tkan-shop.git
cd tkan-shop

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить секреты
cp config.example.py config.py
# Откройте config.py и впишите свои SECRET_KEY и ADMIN_PASSWORD

# 5. Запустить
python app.py
```

### Открыть в браузере

```
http://127.0.0.1:5000
```

### При первом запуске

- ✅ Создаётся база данных `shop.db`
- ✅ Добавляются **33 товара**
- ✅ Создаются **3 демо-промокода**

## 🏗 Архитектура

### 🏭 Application Factory

Точка входа — `create_app()` в `app.py`. Позволяет:
- Легко тестировать приложение
- Не захламлять глобальное состояние
- Использовать несколько экземпляров

### 🔵 Blueprints

| Blueprint | Префикс | Ответственность |
|:---:|:---:|:---|
| `auth_bp` | `/login`, `/register`, `/profile` | Аутентификация |
| `catalog_bp` | `/`, `/catalog`, `/product` | Каталог и товары |
| `cart_bp` | `/cart` | Корзина и checkout |
| `wishlist_bp` | `/wishlist` | Избранное |
| `admin_bp` | `/admin` | Админка |
| `pages_bp` | `/about`, `/contacts` | Статические страницы |

### 🧱 Слои

```
┌─────────────────────────────────────┐
│  Presentation — Jinja2 + CSS        │
├─────────────────────────────────────┤
│  Views — Flask Blueprints           │
├─────────────────────────────────────┤
│  Business Logic — helpers.py        │
├─────────────────────────────────────┤
│  Data Access — db.py (SQLite)       │
├─────────────────────────────────────┤
│  Domain — таблицы БД                │
└─────────────────────────────────────┘
```
